# 认证升级后续事项

## 当前未覆盖

- Passkey 仅支持绑定和删除，尚未提供重命名能力
- 设备会话已支持列表与单条撤销，但尚未展示更丰富的活动信息，例如最近活跃时间和更友好的设备识别
- 账号中心已支持已有角色之间切换，但尚未提供角色开通、停用和成员状态管理界面
- 顶部导航已增加“账号中心”入口，但尚未补充更系统的账户安全提示和登录活动反馈
- 演示登录兼容链路仍保留开关，后续可根据部署策略决定是否彻底移除

## 后续可选增强

- 增加 Passkey 重命名与设备标签管理
- 为设备会话增加“当前设备”外的更多上下文字段，如 IP、浏览器、最近使用时间
- 为账号中心增加单角色开通引导和角色状态说明
- 增加首次登录引导用户绑定 Passkey 的安全增强流程
- 增加认证事件审计、登录失败限流、新设备提醒等安全增强能力
- 评估后续 OAuth / MFA / 企业 SSO 的扩展接入路径
