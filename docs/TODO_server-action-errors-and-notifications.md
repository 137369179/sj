# 后续待办：Server Action 错误回显与摊主通知 UI 后续事项

## 当前未覆盖

- 通知列表暂不支持分页，随着时间推移，通知记录增多可能会导致性能或体验问题。
- 当前“已读”状态更新需要点击特定按钮并触发 API 请求，如果能做到“浏览即已读”或“一键全部已读”会进一步提升体验。
- 对于 `ZodError` 产生的多字段错误，当前表单能够回显错误文本，但在个别极端情况下输入值本身丢失的问题（没有使用 `useActionState` 导致的纯受控回填困难）依然存在。

## 后续可选增强

- **全局通知中心**：在顶部导航栏增加铃铛图标和未读数量气泡。
- **消息分类与推送**：支持站内信与邮件/短信推送联动，提供用户级别的消息防打扰设置。
- **统一表单状态管理**：使用 React 19 的 `useActionState` 彻底重构表单状态管理，实现更优雅的原生错误回显与输入保留。

## 环境备注

- 当前 `pnpm --filter web test` 零错误通过。
- 未引入新的外部依赖，直接使用了现有的 Prisma 模型和 Next.js App Router 约定。
