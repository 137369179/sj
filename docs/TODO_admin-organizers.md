# 后续待办：平台运营与审核后台 (P3-1)

## 当前状态与未覆盖项

- **入驻资质审核 (Approval Flow)**：虽然能够查看主办方，但尚未提供如“封禁”、“审核通过”的操作按钮。目前只要选择 `organizer` 角色登录即视为默认通过。
- **市集巡检流**：主办方发布市集后，理论上应该经过平台巡检才能对外展示给摊主。目前只要主办方发布，即时全网可见。
- **分页与搜索**：主办方列表目前未加入分页，若平台做大，可能会有性能和可用性瓶颈。

## 后续可选增强

1. **主办方入驻审批流**
   - 增加 `User.isVerified`（或抽出独立的 `OrganizerProfile` 包含公司执照、法人信息等），由管理员在后台点击审核通过。未通过的主办方不能发布市集。
   
2. **市集上架审核**
   - 将 `MarketStatus.published` 拆分为 `pending_platform_review` 和 `active`，发布行为必须由 Admin 执行最后一步确认。

3. **黑名单与下架管理**
   - 在管理员后台提供“紧急下架市集”或“冻结主办方账号”的强干预手段。
