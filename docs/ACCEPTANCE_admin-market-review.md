# 验收摘要：市集大盘巡检与上架审核 (P3-1 终篇)

## 1. 验证目标

- **全平台市集监控**：允许平台管理员对所有主办方创建的市集进行统筹和干预。
- **强制阻断机制**：改变原本“主办方一发布摊主即刻可见”的弱监管模式，强制引入平台终审。

## 2. 功能完整性

### 2.1 底层模型升级
- `Market` 模型新增 `isPlatformApproved Boolean @default(false)` 字段。
- 摊主端列表查询（`listPublishedMarkets`）强制追加 `isPlatformApproved: true` 的拦截网，确保摊主绝对无法看到未经巡检的市集。

### 2.2 平台管理 UI (`/admin/markets`)
- 新增**“市集大盘巡检”**后台面板，列表展示所有市集及其关键漏斗指标（摊位数、报名数）。
- **审批按钮**：针对状态为 `published` 但尚未通过巡检的市集，显示“通过上架审核”按钮。
- **强制下架**：针对任何非草稿态的市集，提供红色的“强制下架/退回草稿”按钮。点击后不仅会驳回认证状态，还会强制将市集打回 `draft`。

### 2.3 主办方体验闭环 (`/organizer/markets`)
- 当主办方发布市集后，状态栏会显示特有的黄色 Badge：“平台巡检中”，明确告知主办方当前状态处于平台拦截期，消除体验盲区。

## 3. 代码质量与环境说明

- 彻底解耦 `status`（市集生命周期）与 `isPlatformApproved`（平台内容风控）。
- 为相关逻辑增加覆盖，**全站 168 个测试用例，100% 绿灯通过**。
- `prisma/seed.ts` 已同步更新，支持快速生成巡检中与已上架的模拟数据。
