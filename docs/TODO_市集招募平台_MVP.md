## 2. 当前状态说明

## 3. P0：下一轮必须优先处理

### P0-1 摊位分配事务化

- 当前摊位分配逻辑已成立，但还不是事务包裹
- 下一步应：
  - 用数据库事务包住摊位分配
  - 避免并发分配导致竞争窗口
  - 为并发冲突补更聚焦的回归测试

### P0-2 生产级认证与会话增强

- 当前登录与身份校验已具备可视化 UI 与退出链路，但底层仍是 session stub
- 下一步应：
  - 增加更真实的登录态管理与真实注册链路
  - 补充 session 过期和签名防伪机制
  - 彻底收紧跨角色访问与权限边界

### P0-3 跨字段时间业务校验

- 当前建市集时间字段已具备字段级和多字段错误反馈
- 但仍未处理“开始时间晚于结束时间”等跨字段规则
- 下一步应：
  - 在共享输入契约中加入时间先后关系校验
  - 页面与 API 统一承接跨字段错误语义
